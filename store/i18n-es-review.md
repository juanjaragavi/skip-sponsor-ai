# SkipSponsor AI — Spanish copy review (S-P1-4)

For Juan's approval before release. Every string the extension shows comes
from `public/_locales/<lang>/messages.json`; this sheet lists all
152 keys side by side, then the Chrome Web Store listing
(`store/listing.md` → `store/listing.es.md`).

Rules applied: neutral international Spanish (BRAND-07), _usted_, "video"
(not "vídeo"), no country references (GLOBAL-02), no new claims; "SkipSponsor
AI" and "YouTube" untranslated. Product terms: sponsor read = mención
patrocinada, Auto-skip = Omitir automáticamente, Notify = Avisar, Off =
Desactivado, Undo = Deshacer, Skip = Omitir, captions = subtítulos.
`$NAME$` tokens are filled in by the extension (times use the user's own
locale format). Limit-notice subtitles (`limit*Sub`) are capped at 48
characters with the time filled in, in both languages (tested).

Points to look at first (judgement calls):

1. `modeAutoShort` = **Automático**: the popup's mode button is too narrow
   for "Omitir automáticamente" (it wrapped and clipped); the help line under
   it and Settings use the full term.
2. Row tags `tagCut` / `tagAsk` / `tagKeep` = **CORTE / AVISO / QUEDA**:
   short editor-style tags; "QUEDA" (the segment stays and plays) is the
   least obvious.
3. `limitInstallQuotaSub` / `limitGlobalBudgetSub` = "Omite lo ya analizado ·
   …": shortened to fit 48 characters with a time such as "12:00 p. m.".
   `limitSettingUpSub` "Sin omisiones" stands for "Plays normally".
4. `privacyController` and `privacyShareUsageHint` describe data handling;
   they follow `PRIVACY.es.md` wording but are legal-adjacent (TRUTH-04).
5. Percentages: the UI keeps "78%" (no space) like the English UI; the store
   description uses "96,8 %" and "50–95 %" (decimal comma and a space, as in
   the earlier Spanish draft).
